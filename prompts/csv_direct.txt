**ROLE:** You are transcribing a handwritten hospital duty rota from an image directly into an Excel (`.xlsx`) workbook.

Your priority is **structural accuracy first, cell-location accuracy second, handwriting recognition third**.

Do not summarize, interpret, or redesign the rota.

## 1. IDENTIFY THE PAGE STRUCTURE

Before reading individual handwriting, identify:

1. Table/grid boundaries.
2. Header rows.
3. Date columns.
4. Staff/identifier columns.
5. Every staff row.
6. Special rows such as `DEP I/C`, `SUPPORT STAFF`, and `RATIO`.
7. Footer and marginal areas.

The page is upright.

Preserve the source structure.

**Never delete, collapse, merge, reorder, renumber, or skip a visible row or column.**

A visually blank staff row is still a real row and must be represented in Excel.

Use the printed staff/row number as the primary row anchor.

A week/date block is one table and must remain one table.

## 2. LOCATE EACH MARK BEFORE RECOGNIZING IT

Determine which cell contains each visible mark using:

* visible row boundaries,
* visible column boundaries,
* alignment with the date header,
* alignment with the staff row.

Do not assign a mark to a neighboring cell merely because it is visually close.

Do not merge separate marks because they are close together.

Do not move a mark to a different cell to make the rota appear more logical.

Every staff × date intersection must receive exactly one cell state:

* a valid transcribed value,
* empty if the source cell is clearly blank, or
* `[unclear]` if the cell is identifiable but its contents cannot be confidently read.

If a mark is visible but its column cannot be determined, use `[column unclear]`.

## 3. ORDINARY NURSE SHIFT CELLS

For ordinary nurse shift cells, the **only permitted final values** are:

`M`, `N`, `No`, `D`, `Do`, `PH`, `E`, `[unclear]`

Meanings:

* `M` = afternoon shift
* `N` = night shift
* `No` = night off
* `D` = day shift
* `Do` = day off
* `PH` = public holiday
* `E` = evening shift

### HANDWRITING NORMALIZATION

A handwritten `M` may resemble an upside-down `3`.

A handwritten `N` may resemble `Z` or an upside-down `Z`.

In ordinary nurse shift cells:

* Interpret the upside-down `3` handwriting form as `M`.
* Interpret the Z-shaped handwriting form as `N`.

These are **handwriting representations**, not literal output characters.

Therefore:

* Never output `Z` as an ordinary shift value.
* Never output `3` as an ordinary shift value.
* Never output `Z3`, `Zm`, `Z2`, or similar visual/OCR artifacts as an ordinary shift value.
* If the handwriting cannot confidently be normalized to one of the seven valid shift codes, output `[unclear]`.

Do not apply these handwriting corrections to dates, `DEP I/C`, `RATIO`, or other numeric/non-shift cells.

## 4. SPECIAL ROWS

### DEP I/C

`DEP I/C` contains genuine numeric values.

* Preserve each value in its exact date column.
* Transcribe the visible number.
* Do not convert numbers into shift codes.

### RATIO

Each RATIO cell is one **atomic cell value**.

The expected format is:

`a/b/c`

For example:

`3/2/1`

Rules:

* Preserve the complete value in the same cell.
* Exactly three numeric values are separated by two `/` characters.
* Never split the ratio across multiple cells.
* Never combine numbers from neighboring cells.
* Never convert the numbers into shift codes.
* Transcribe the ratio itself rather than explaining its meaning.

### SPANNING-WORD ROWS

If letters occupy consecutive cells, preserve each letter in its corresponding cell.

Example:

`S | C | H | O | O | L`

Do not force these letters into shift codes.

### MULTI-VALUE CELLS

If two distinct values are clearly stacked vertically inside one cell, preserve their order as:

`top / bottom`

Do not combine them into a single shift code.

### MARGINAL ANNOTATIONS

Preserve annotations such as:

`5PH`, `6NO`, `2DO`

verbatim in their corresponding location.

## 5. EXCEL STRUCTURE

Create an `.xlsx` workbook.

Preserve the original table structure as closely as possible.

For each week/date block:

* Keep it as one contiguous table.
* Preserve all source rows, including blank rows.
* Preserve all source columns.
* Preserve the original left-to-right date order.
* Keep staff/identifier columns before the date columns.
* Do not remove empty columns.
* Do not add invented rows or columns.

A genuinely blank source cell should remain an **empty Excel cell**, not the text `[blank]`.

Use `[unclear]` only when the cell contains a visible entry that cannot be confidently transcribed.

Use `[column unclear]` only when a visible mark cannot confidently be assigned to a column.

Keep ordinary shift codes as text.

Keep genuine numeric values in `DEP I/C` and RATIO cells as their source values. Preserve RATIO values such as `3/2/1` as text so that Excel does not alter their format.

## 6. FINAL VALIDATION BEFORE SAVING

Before creating the final workbook, internally verify:

1. Every visible staff row is present.
2. No staff row has been skipped.
3. Blank rows remain present.
4. Staff row numbers remain in their original order.
5. Every date column is present and in its original order.
6. No ordinary shift cell contains an invalid value.
7. Ordinary shift cells contain only:
   `M`, `N`, `No`, `D`, `Do`, `PH`, `E`, or `[unclear]`.
8. `Z`, `Z3`, `Zm`, `Z2`, `3`, and similar OCR artifacts do not appear in ordinary shift cells.
9. Every RATIO value remains one complete `a/b/c` cell.
10. `DEP I/C` numeric values remain numeric values and are not converted to shift codes.
11. No mark has been moved to a neighboring cell.
12. No rows or columns have been removed because they appear empty.

Only after this validation should the `.xlsx` workbook be produced.
